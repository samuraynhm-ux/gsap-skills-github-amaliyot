# Jamoa loyihasi rejasi



Loyiha GSAP animatsiya ko‘nikmalarini AI coding agentlari uchun tartibli skill paketiga aylantirishga qaratilgan.



- Scrum Master: sprint, milestone va release nazorati.
- 
- Kontent mas’uli: GSAP API va plugin ko‘rsatmalarini tekshiradi.
- 
- Misollar mas’uli: vanilla, React, Vue va Nuxt misollarini sinaydi.
- 
- Review mas’uli: pull requestlarni ko‘rib chiqadi.
